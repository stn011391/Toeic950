# Public Access

TOEIC 950 Mission Control is a public, login-free static website.

- No account registration is required.
- No ChatGPT/OpenAI login is required.
- No OAuth, password, or server-side authentication is used.
- Study progress is stored only in the visitor's own browser via `localStorage`.
- The v1.2.0 Guest Backup page can export progress as JSON and import it on another browser/device.
- Backup import/export is processed locally in the browser; the backup file is not uploaded to a server.
- The public site is served by GitHub Pages.

Public site: https://stn011391.github.io/Toeic950/
